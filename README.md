# Uptime Academy

Practical help with AI, work and life, drawn from Uptime's learning library.
Explore ideas from books, courses and podcasts, then put them to work in your
own situation.

## Connect and start

**Claude Code**

1. Install Uptime Academy:

   ```
   /plugin install uptime-academy --marketplace jamie935/uptime-academy-claude
   ```

   On older Claude Code versions, run
   `/plugin marketplace add jamie935/uptime-academy-claude`, then
   `/plugin install uptime-academy@uptime`.
2. Type `/mcp`, choose **uptime-academy**, then **Authenticate**.
3. Complete Uptime's sign-in page, then ask your learning question.

**Claude desktop or claude.ai**

1. Add **Uptime Academy** to Claude.
2. Open its **Connectors** tab and choose **Connect**.
3. Complete Uptime's sign-in page, then start a new chat.

Try, for example:

- "What can I learn from Atomic Habits? Show me its Uptime Hack."
- "I work in marketing. How can GitHub help me review a website change?"
- "Help me prepare for a difficult conversation with someone on my team."

Never paste a sign-in code or password into chat. Uptime's own sign-in page
connects your account.

Your questions can be in your own language. Say **"show memory"** to see your
saved learning context, or **"clear memory"** to remove it. Opening a Hack may
depend on your Uptime membership.
